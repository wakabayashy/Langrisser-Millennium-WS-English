# Langrisser Millennium WS: The Last Century — English Translation v1.0

**The complete English translation for the original monochrome Bandai WonderSwan is here!**

In collaboration with [@Cloogr](https://retrogametalk.com/members/1163345/), I'm happy to announce that **we've fully translated Langrisser Millennium for the WonderSwan!**

**Special thanks** to [@Last_Seraph](https://retrogametalk.com/members/27874/) and [@altaihero](https://retrogametalk.com/members/19247/) for playtesting and bug reports. Definitely a team effort!

## Download

Download the two optional **BPS patch files** under **Assets** at the bottom of this release:

- **`langrisser-millennium-en-1.0.bps`** — complete English translation (standard version).
- **`langrisser-millennium-en-teststage-1.0.bps`** — same translation, with access to the hidden developer Test Stage.

**These files are patches, not ROMs.** You only need **one** BPS file to patch your own original Japanese ROM.

This is the same **v1.0** that we released together, also available through [Swan Revival](https://swanrevival.com/translations/langrisser-millennium/) and [our collaborator's GitHub release](https://github.com/PokemonGoDB/wonderswan-english-patches/releases/tag/langrisser-millennium-v1.0).

## What's translated?

- All story and battle dialogue, across both routes and hidden stages.
- Title screen, menus, scenario introductions, victory/defeat conditions, items, spells, shop, mercenary and deployment interfaces.
- Battle commands, unit and class information, level ups, results, save/load menus and staff credits.
- All four endings.
- English-specific text rendering and fonts adapted for WonderSwan display.

This is an **AI-assisted fan translation** with substantial human review, technical work and playtesting. No professional translation standard is claimed.

## Installing the patch

1. Use your own original Japanese **Langrisser Millennium WS - The Last Century (Japan).ws** ROM (1,048,576 bytes; CRC32 `9E0854E2`).
2. Choose **one** of the `.bps` files from this release.
3. Apply it with the [Swan Revival patcher](https://swanrevival.com/patcher/) or another BPS-compatible patcher such as Floating IPS.
4. Keep the resulting file with a `.ws` extension.

| Version | Expected patched ROM CRC32 |
| --- | --- |
| Standard English v1.0 | `66242FE6` |
| Test Stage v1.0 | `527761BF` |

The patched file should remain 1,048,576 bytes. Japanese version save data is compatible.

**Test Stage edition:** Hold any Y button while selecting **Start** at the title screen. The opening and quiz play first; the unused developer stage follows.

## Feedback and known limitations

The game is lengthy, so if you encounter Japanese text, broken layouts, crashes, or awkward translation, please let us know with a screenshot, scenario and details.

The public v1.0 notes document automated emulator-based checks and human playtesting. They do **not** claim a test on real WonderSwan hardware. Some rare save/load error screens were not observed in testing. See the [full technical notes](https://github.com/PokemonGoDB/wonderswan-english-patches/releases/tag/langrisser-millennium-v1.0).
