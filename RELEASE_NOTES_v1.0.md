## What's new in v1.0

- Complete English story translation across both routes, including hidden stages
- Translated menus, dialogue, battle text, items, magic, classes and endings
- Updated text rendering and fonts for English
- Compatibility with existing Japanese-version save data
- Optional developer Test Stage edition

**Original Japanese ROM:** 1,048,576 bytes, CRC32 `9E0854E2`  
**Patched English ROM:** CRC32 `66242FE6`  
**Patched Test Stage ROM:** CRC32 `527761BF`

Apply one BPS patch to the original Japanese `.ws` file with the [Swan Revival Patcher](https://swanrevival.com/patcher/) or another BPS-compatible patcher.

This translation was AI-assisted and reviewed/tested by people; if you run into missing text, bugs or awkward translations, please report them with a screenshot and scenario details.

**Note:** This document is a publication reference for the final v1.0. The existing Beta 1 release in this repository remains an older build, not v1.0.
